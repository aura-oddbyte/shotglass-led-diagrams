# Shot-glass LED display wiring diagrams

Original planning diagrams for the [Oddbyte illustrated wiring guide](https://oddbyte.us/2026/10/illustrated-shot-glass-led-display-wiring/).

- [`shotglass-power-distribution.png`](shotglass-power-distribution.png) — conceptual 12 V power supply and fused DC distribution for three reels.
- [`shotglass-data-cubbies.png`](shotglass-data-cubbies.png) — three independent ESP32/WLED data lanes and four-LED cubby mapping.

These are **conceptual DC topology diagrams**, not mains installation drawings or pin-numbered construction schematics. End-of-reel power injection is specified but not individually drawn. Select actual wire gauges, fuse ratings, connectors, and injection points for the measured cabinet and verify at full load. Have a qualified person handle unfamiliar AC work.
